# 🚀 My Machine Learning Journey

Welcome to my Machine Learning learning journal! This repository serves as a structured documentation of my transition from a mathematics graduate into data science. It tracks my progressive understanding of algorithmic logic, mathematical implementations, and model evaluation metrics.

Instead of just copying code, my goal is to break down concepts directly, grasp the underlying logic, and implement solutions systematically.

---

## 🗺️ Learning Roadmap & Topics Covered

### 📁 01. Data Preprocessing & Foundations
* **Feature Scaling:** Understanding how and when to apply `StandardScaler` to ensure uniform feature distribution.
* **Synthetic Data Generation:** Utilizing `make_regression` and `make_classification` to build controlled testing environments with varying feature densities.
* **Handling Messy Data:** Simulating real-world scenarios by injecting `noise` into synthetic environments.

### 📁 02. Linear & Regularized Models
* **Linear Regression:** Establishing baselines for continuous target prediction.
* **Lasso Regression (L1 Penalty):** Observing automatic feature selection and how the alpha penalty forces non-informative coefficients to exactly `0`.
* **Ridge Regression (L2 Penalty):** Understanding coefficient shrinkage without losing dimensional features.
* **Visualizing Coefficients:** Mapping Lasso vs. Ridge weights to study regularization penalties graphically.

### 📁 03. Model Evaluation & Performance Metrics
* **R² Score (Coefficient of Determination):** Interpreting model fit variance (e.g., distinguishing an overfitted $R^2 = 1.0$ baseline from realistic noisy models).
* **Error Metrics:** Calculating Mean Squared Error (MSE) and Mean Absolute Error (MAE) for evaluation.
